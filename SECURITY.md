# Security Policy

## Supported versions

The project currently maintains support for the Node.js versions covered by CI:

- Node.js 20
- Node.js 22
- Node.js 24

## Reporting vulnerabilities

Please report vulnerabilities privately through GitHub's security advisory flow if available for this repository.

If that is not possible, contact the maintainer through the repository's configured security contact and do not open a public issue until a fix has been prepared.

## Response expectations

We will review reports as quickly as possible and aim to provide an initial response promptly, followed by a fix or remediation plan when appropriate.
