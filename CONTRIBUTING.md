# Contributing

Thanks for helping improve `lp_solve`.

## Development setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Build the native addon:
   ```bash
   npm run build
   ```
3. Run the test suite:
   ```bash
   npm test
   ```

## Supported environments

This project currently targets Node.js 20, 22, and 24 in CI.

## Pull requests

- Keep changes focused and easy to review.
- Add or update tests for behavioral changes.
- Verify the native addon builds successfully before submitting.
- Include a brief summary of the change and any compatibility notes.

## Release notes

Use the changelog file for user-visible changes.
